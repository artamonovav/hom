The full local copy is in the "site" directory.

Windows 10/11
-------------
Double-click start.cmd.
If the drive supports autorun, autorun.inf starts it automatically.
No Python is required; the built-in PowerShell 5.1 server is used.

Linux
-----
Run:
    ./start-linux.sh

Python 3 is required on Linux (standard library only).
The site is served at http://127.0.0.1:8000/ and opened in the browser.
Press Ctrl+C in the terminal to stop the server.

The pages are a machine translation from Japanese. The original Japanese
pages are available from the banner on every translated page.
