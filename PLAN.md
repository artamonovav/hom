# План: локальная копия и перевод руководства Honda Freed (webom)

## 1. Что представляет собой источник

- Корень: `https://www.honda.co.jp/ownersmanual/webom/jpn/freed/2020/`
- Страницы — обычный серверный HTML (не SPA). Контент доступен без JS.
- На 2020 год: ~355 содержательных страниц (`details/*.html`, `detailsnavi/*.html`, `pc/*.html`) + главная.
- Навигация на страницах деталей подставляется из `js/url.js` (переменная `MENU`).
- Картинки и CSS/JS — статические файлы (`img/`, `images/`, `css/`, `js/`, `/font/`).
- `robots.txt` запрещает только `/ridersvoice/`; обход руководства разрешён.
- Родительская страница `.../freed/` содержит список годов: 2026, 2025, 2023, 2020, 2017.
- Текст на иллюстрациях (приборы, кнопки) — часть PNG, отдельная задача (OCR), в v1 не переводится.

## 2. Архитектура решения

Пять независимых, повторяемых этапов. Каждый этап идемпотентен и кэширует результат,
поэтому можно прерывать и продолжать без потери прогресса.

1. **Обход (crawl)** — BFS по ссылкам внутри года, сохранение сырого HTML.
2. **Ассеты** — скачивание картинок, CSS, JS, шрифтов, PDF/видео; рекурсивно по CSS.
3. **Перевод** — извлечение текстовых блоков, батч-перевод, кэш в SQLite, сборка переведённых HTML.
4. **Сборка сайта** — два офлайн-дерева (`/` — японский оригинал, `/ru/` — перевод),
   переписывание ссылок, отключение внешней аналитики, перевод меню.
5. **Масштабирование** — цикл по годам/моделям с теми же командами.

### Перевод

Переводится не «страница целиком», а **листовые блоки** (абзацы, пункты списков, ячейки таблиц,
заголовки) вместе с inline-разметкой (`<a>`, `<span>`, `<sup>`, `<br>`), чтобы сохранить ссылки,
якоря и ids. Провайдеры:

| Провайдер | Ключ | Качество JA→RU | Стоимость |
|---|---|---|---|
| `google-web` (по умолчанию) | не нужен | хорошее | бесплатно, неофициальный endpoint |
| `deepl` | `DEEPL_API_KEY` | лучшее | free 1 млн знаков/мес (актуальный лимит аккаунта — в `/v2/usage`) |
| `yandex` | `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | хорошее | триал/платно |
| `ollama` | локально | среднее, медленно | бесплатно |
| `openai` | `OPENAI_API_KEY` | хорошее | платно |

Кэш перевода — `data/translate.sqlite` (ключ = hash исходного блока + провайдер + язык).
Повторный запуск не платит дважды и не зависит от порядка страниц.
Глоссарий терминов — `glossary/ru.json` (пост-редактирование).

Поверх кэша есть таблица `overrides`: переводы DeepL для выбранных (самых частых)
блоков. При сборке overrides имеют приоритет, а остальное берётся из `google-web`.
Команда `webom freq` считает вхождения блоков по всем страницам/годам,
`webom deepl --budget auto` переводит их по убыванию частоты в пределах остатка
квоты DeepL (через `/v2/usage`) и складывает в `overrides`.

### Ограничения v1

- Текст внутри картинок остаётся на японском. Опционально позже: Tesseract (`jpn`) +
  перевод + подрисовка подписей/оверлей.
- Машинный перевод требует вычитки, особенно предупреждения по безопасности.
- Офлайн-сайт рассчитан на запуск через локальный HTTP-сервер (`webom serve`),
  т.к. ссылки внутри дерева корневые (`/ownersmanual/...`). Так работает и RU-копия,
  использующая общие картинки из JA-дерева (без дублирования 100+ МБ).

## 3. Что нужно установить

Обязательное (уже есть в системе):

```bash
sudo apt install python3 python3-venv python3-bs4 python3-lxml
```

Python-зависимости (ставятся в `.venv`): `requests`, `beautifulsoup4`, `lxml`.

Опционально:
- ключ DeepL/Yandex — если нужен перевод выше качеством;
- `tesseract-ocr tesseract-ocr-jpn` — только для будущего OCR картинок.

## 4. Структура проекта

```
freed/
├── PLAN.md
├── README.md
├── requirements.txt
├── Makefile
├── webom/                 # пакет
│   ├── cli.py             # команды crawl / translate / build / serve / years
│   ├── net.py             # вежливый HTTP-клиент (retry, rate limit)
│   ├── crawl.py           # обход страниц
│   ├── assets.py          # сбор и скачивание ресурсов
│   ├── blocks.py          # извлечение/вставка переводимых блоков
│   ├── providers.py       # google-web / deepl / yandex / ollama / openai
│   ├── translate.py       # батчи, кэш, сборка переведённых страниц
│   └── build.py           # офлайн-деревья site/ и переписывание ссылок
├── glossary/ru.json
├── data/
│   ├── raw/freed/2020/...       # сырой HTML
│   ├── assets/www.honda.co.jp/... # картинки, css, js, шрифты
│   ├── translated/ru/...        # переведённый HTML
│   ├── manifests/               # список страниц
│   └── translate.sqlite         # кэш переводов
└── site/
    ├── index.html               # точка входа
    ├── ownersmanual/...         # японский оригинал
    ├── ru/ownersmanual/...      # русская версия
    ├── font/, common/...        # общие ресурсы
```

## 5. Команды

```bash
make crawl        # обход + ассеты (2020)
make translate    # перевод (по умолчанию google-web)
make build        # сборка site/
make serve        # http://127.0.0.1:8000/
```

Эквивалент:

```bash
.venv/bin/python -m webom crawl --car freed --year 2020
.venv/bin/python -m webom translate --car freed --year 2020 --provider google-web
.venv/bin/python -m webom build --car freed --year 2020
.venv/bin/python -m webom serve
```

## 6. Порядок работ и оценки

| Этап | Объём | Время |
|---|---|---|
| Обход 2020 | ~360 HTML | 5–8 мин (1 запрос/сек) |
| Ассеты | ~500–900 файлов | 2–5 мин |
| Перевод | ~0,5–1 млн знаков | 10–30 мин (google-web) |
| Сборка | — | < 1 мин |
| Вычитка/глоссарий | вручную | по желанию |

## 7. Масштабирование на все годы

```bash
.venv/bin/python -m webom years --car freed
for y in $(.venv/bin/python -m webom years --car freed); do
  .venv/bin/python -m webom crawl     --car freed --year "$y"
  .venv/bin/python -m webom translate --car freed --year "$y"
  .venv/bin/python -m webom build     --car freed --year "$y"
done
```

Кэш переводов общий: одинаковые формулировки между годами переводятся один раз.
Для других моделей достаточно `--car <model>`.

## 8. Критерии готовности

- Все страницы года открываются локально, ссылки и якоря работают.
- Картинки/CSS/JS отдаются локально, внешние трекеры отключены.
- Русская версия доступна по `/ru/...`, переключатель на оригинал есть на каждой странице.
- Меню и заголовки переведены.
- Отчёт о покрытии перевода: `data/reports/translation-ru.json`.

## 9. Итог (2026-10-22)

Собраны все пять лет: 2017, 2020, 2023, 2025, 2026 — 1 245 страниц на язык
(321 + 321 + 150 + 223 + 230), включая `agreement.html`, который загружается
скриптом, а не ссылкой из навигации. Перевод: 0 пропусков, 0 ошибок.

Проверка после DeepL: 47 201 внутренняя ссылка/ресурс — битых нет; все `id`
сохранены; реального японского текста в русских страницах не осталось (кроме
служебной подписи «Открыть оригинал (日本語)»).

Руководства 2025–2026 используют новый формат: контент лежит в `details/…`, а меню
строится JS из `language/ja_JP/main/json/contentsDB.json`. Обход дополнительно
читает эту JSON-базу, переводчик переводит заголовки меню, сборка кладёт японскую и
русскую копии JSON рядом с деревьями страниц и убирает записи без локальной страницы.

Дополнительно сканер ресурсов разбирает не только HTML/CSS, но и JS/JSON: так
догружены `asset/images/mark.png`, `logo.png`, `dOM.png`, `masonry.pkgd.min.js`,
`visualindex_content.json`, `inline.json` и картинки для интерактивных схем.
Сборка зеркалирует небольшие общие каталоги (`asset`, `images`, `css`,
`javascript`, `js`, `pc/js`, `details/js`) в русское дерево, копирует только
реально упомянутые из JS/JSON файлы `img/` и исправляет `is_index()` для пути
`/ru/...`. Локальный сервер (`serve.py`, `webom serve`) дополнительно умеет
отдавать общий японский файл, если скрипт всё же построил относительный путь
без года или без `/ru`.

Для Windows добавлен `serve-freed.ps1` — нативный статический сервер на
PowerShell 5.1 / .NET `HttpListener`, без Python и без прав администратора.
`start-freed.cmd` и `start-freed.ps1` запускают именно его; Linux-версия
`serve.py` остаётся для `make serve` и разработки.

Поле `contentsDB.text` в русской копии теперь не переводится отдельно, а
заполняется видимым текстом соответствующей русской страницы `details/…` или
`detailsnavi/…`. Это даёт русский поисковый индекс без расхода DeepL.

Подсказки на интерактивных схемах вынесены в данные, а не в HTML: для 2025–2026
это `visualindex_content.json`, для 2017–2023 — поля `caption` в
`pc/js/data/appearance.point.js` и `interior.point.js`. `webom translate`
переводит их тем же кэшем, а `build` кладёт русские копии в `site/ru` и
переключает старые страницы на переведённые JS-файлы.

Окно соглашения с условиями использования отключено в обеих языковых версиях:
сборка патчит `agreement()` в `common.js` (2025–2026) и
`Library.agreement.showAgreement()` в `library.js` (2017–2023), а к URL этих
скриптов добавляется `?v=webom-no-agreement-1`, чтобы сбросить старый кэш.

Оптимизации: сборка копирует только изменившиеся ассеты (размер + mtime);
локальные серверы отдают HTML/JS/JSON с `no-cache`, а картинки/шрифты — с
`public, max-age=86400`, поддерживают `If-Modified-Since`/304; нативный сервер
стримит файлы вместо чтения целиком. Добавлены `make verify` (ссылки, число
страниц, остатки японского) и `make iso` (два воспроизводимых ISO из
`packaging/`: 2017–2023 и 2025–2026).

Частотность: 20 699 уникальных блоков, 43 989 вхождений, 569 235 «биллинговых»
знаков текста (1 422 126 знаков вместе с разметкой). После дополнительного
DeepL-прохода покрыты все 20 699 блоков страниц, 727 заголовков меню и подсказки
на схемах; всего 21 580 overrides, `deepl_failures` — 0. Израсходовано
638 208 из 1 000 000 знаков, осталось 361 792.
