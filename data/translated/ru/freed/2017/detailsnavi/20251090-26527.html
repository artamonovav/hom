Показать меню навигации

  • Кнопка «HOME»
  • Навигация
  • Кнопка MENU

Различные функции навигации, такие как установка пункта назначения и изменение маршрута, доступны в меню навигации.

Выберите один из пунктов.
Вы можете выбрать один из следующих пунктов.
  • Пункт назначения: мы ищем пункт назначения и промежуточные пункты различными способами.

    Поиск пункта назначения

  • Поиск поблизости: поиск объектов, расположенных рядом с текущим местоположением.

    Поиск в окрестностях текущего местоположения

  • Маршрут: здесь можно редактировать маршрут, например, изменять его или добавлять промежуточные пункты.

    Изменить маршрут

  • Зарегистрированные точки: отображает список зарегистрированных точек, например, избранных мест. Вы можете выбрать точку из списка в качестве пункта назначения.

    Поиск по месту регистрации

  • История пунктов назначения: выберите пункт назначения из истории.

    Поиск по истории пунктов назначения

  • Редактирование сохраненных точек: можно редактировать метки и названия сохраненных точек, например, любимых мест.

    Редактировать название зарегистрированного места

  • Информация: можно просмотреть данные о дорожной обстановке, полученные от VICS и InterNavi, данные о местоположении по GPS, а также информацию о версии навигатора.

    Проверить информацию

  • Настройки навигации: здесь можно выполнить различные настройки, связанные с навигацией.

    Настройки навигатора
