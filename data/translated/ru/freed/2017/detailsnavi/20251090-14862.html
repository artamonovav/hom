О GPS

Honda Система InterNavi определяет местоположение двумя способами: с помощью GPS и автономной навигации.

Определение местоположения с помощью GPS

GPS (Global Positioning System — глобальная система позиционирования) — это система, которая определяет текущее местоположение путем приёма радиосигналов с спутников GPS, предназначенных для измерения координат.

Спутники GPS запущены на орбиту вокруг Земли на высоте 21 000 км, и определение местоположения становится возможным при приеме радиосигналов от трёх и более спутников. Существует два вида определения местоположения с помощью GPS: трёхмерное и двумерное.

Трехмерная локализация

Определение местоположения осуществляется по широте, долготе и высоте. Этот метод определения местоположения используется в случае хорошего приема сигналов от четырёх и более спутников GPS.

Двумерное позиционирование

Когда качество приема сигнала GPS-спутников не очень хорошее, определение местоположения осуществляется в двух измерениях — по широте и долготе. Поскольку высота не определяется, погрешность определения местоположения будет несколько больше, чем при трёхмерном определении.

Определение местоположения с помощью автономной навигации

Это метод определения текущего местоположения на основе анализа импульсов скорости движения для определения пройденного расстояния и данных вибрационного гироскопа для определения направления поворота.

Особенности определения местоположения с использованием GPS и автономной навигации

  • Даже если не удается принять сигнал от спутников GPS, определение местоположения возможно с помощью автономной навигации.
  • Если использовать только определение местоположения с помощью автономной навигации, отображение текущего местоположения может постепенно смещаться. При сочетании GPS и автономной навигации погрешности автономной навигации корректируются с помощью GPS, что повышает точность определения местоположения.

Механизм повышения точности определения местоположения

3D-гибридный датчик

Устройство оснащено встроенным гибридным 3D-датчиком. Высокоточная 3D-гибридная система, учитывающая перепад высот, определяемый с помощью импульсов скорости движения и гироскопа в режиме автономной навигации, обеспечивает высокую точность определения местоположения.

Обучение и корректировка погрешностей

3D-гибридный датчик постоянно сравнивает рассчитанное им собственным способом текущее местоположение с местоположением, определённым с помощью GPS, и анализирует возникающие погрешности.

В зависимости от содержания обучения мы корректируем погрешности, возникающие под влиянием различных факторов.

По мере накопления данных о пробеге система обучается, благодаря чему точность определения местоположения постепенно повышается.

Сопоставление карт

Поскольку при определении местоположения с помощью GPS или автономной навигации могут возникать погрешности, текущее местоположение может оказаться не на дороге, а, например, на реке. В таких случаях функция сопоставления с картой исходит из того, что «автомобиль движется по дороге», и корректирует текущее местоположение, перемещая его на ближайшую дорогу.

В данной системе сначала осуществляется высокоточное определение местоположения с помощью GPS и автономной навигации, а затем запускается функция сопоставления с картой, что позволяет отображать текущее местоположение с ещё большей точностью.
