Вы можете выбрать один из следующих пунктов.
  • Часто используемые команды: список команд, которые пригодятся при работе.
  • Телефонные команды: список команд для управления телефоном.
  • Аудиокоманды: список команд для управления аудио.
  • Команды кондиционера: список команд для управления кондиционером.
  • Команды на экране: список команд, действующих только на определённых экранах.
  • Команды для поиска песен: список команд для поиска песен на iPod или USB-устройствах.

    Поиск песен с помощью Song By Voice™ (SBV)

  • Основные команды: список команд, относящихся к основным операциям данной системы.
