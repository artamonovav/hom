Вы можете выбрать один из следующих пунктов.
  • Приоритетный тип маршрута: здесь можно установить тип маршрута, который будет учитываться в первую очередь при расчете маршрута. Настройки вступят в силу начиная со следующего расчета маршрута.

    Изменить условия маршрута

  • Учет сезонных ограничений: при расчете маршрута учитываются маршруты, на которых в зависимости от сезона действуют ограничения. (По умолчанию: включено)
  • Учет ограничений по времени: при расчете маршрута учитываются маршруты, на которых действуют ограничения в зависимости от времени суток. (По умолчанию: включено)
  • Учет паромных маршрутов : При расчете маршрута учитываются паромные маршруты. (Значение по умолчанию: не учитывать )
  • Учет «Smart IC»: при расчете маршрута ищется маршрут, проходящий через «Smart IC». (По умолчанию: не учитывать)
  • Расчет стоимости проезда по системе ETC: если система ETC доступна, стоимость проезда по автомагистрали рассчитывается по тарифам ETC. (По умолчанию: не рассчитывать)
  • Отображение указателей маршрута: во время навигации по маршруту отображаются указатели маршрута на обычных дорогах. (По умолчанию: не отображается)

    Отображение информации при движении по общественным дорогам

  • Уведомление о предотвращении движения в обратном направлении по автомагистрали: при обнаружении движения в обратном направлении или движения задним ходом по автомагистрали на основе данных о местоположении автомобиля и картографической информации выдается уведомление с помощью изображения и звукового сигнала. (По умолчанию: включено)
  • Голосовые подсказки на пункте взимания платы: при приближении к пункту взимания платы звучит голосовая подсказка. (По умолчанию: включено)
  • internavi Информация. Голосовые подсказки : Голосовые подсказки по системе InterNavi. (Значение по умолчанию: )

Учет сезонных ограничений, учет ограничений по времени суток
Если информация получается с сервера InterNavi, она учитывается независимо от настроек.

Учет паромных маршрутов
При расчете маршрута на основе данных сервера InterNavi, независимо от настроек, маршруты, проходящие по паромным переправам, не учитываются.

Путеводитель
Во время движения по автомагистрали маршрутный гид отображается постоянно, независимо от настроек.
