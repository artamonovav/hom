Прочие настройки

  • Кнопка «HOME»
  • Настройки
  • Настройки системы
  • Прочее
  1. Выберите один из пунктов и измените значение параметра.
  2. Выберите «Завершить настройку».
Вы можете выбрать один из следующих пунктов.
  • Настройка запоминания последнего экрана: при запуске системы отображается экран с функцией, которая отображалась в последний раз. (Значение по умолчанию: включено)
    • 21.12.2016 Исправление текста KOD Сано
  • Обновление памяти: устанавливает автоматическое обновление памяти в назначенное время, когда режим питания выключен. (Значение по умолчанию: включено)
  • Настройка времени обновления памяти: устанавливается время автоматического обновления памяти. (Значение по умолчанию: 2:00)
    • 21.12.2016 Исправление текста завершено. KOD Сано
  • Настройка чувствительности сенсорной панели: выберите уровень чувствительности сенсорной панели. (Значение по умолчанию: LO)
  • Подробная информация: отображает меню настроек Android.
  • Смена дизайна: позволяет изменить дизайн интерфейса данной системы.
  • Сброс настроек: восстановление заводских настроек.
