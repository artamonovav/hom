Поиск пункта назначения

  • Кнопка «HOME»
  • Навигация
  • Поиск пункта назначения
Вы можете выбрать один из следующих пунктов.
  • 50 звуков: введите название учреждения или географическое название, чтобы найти его.

    Поиск по 50 звукам

  • Адрес: Введите адрес, чтобы найти.

    Поиск по адресу

  • Номер телефона: введите номер телефона для поиска.

    Поиск по номеру телефона

  • История пунктов назначения: выберите пункт назначения из истории.

    Поиск по истории пунктов назначения

  • Зарегистрированные точки: отображает список зарегистрированных точек, например, избранных мест. Вы можете выбрать точку из списка в качестве пункта назначения.

    Поиск по месту регистрации

  • Место последнего поиска: отображает положение курсора в месте, где в последний раз выполнялся поиск.
  • Объекты / Категории: поиск объектов по таким категориям, как мини-маркеты и автозаправочные станции.

    Поиск по объектам/жанрам

  • internavi «Мои места»: internavi Поиск осуществляется по точкам, добавленным в раздел «Мои места» в приложении LINC.

    internavi Поиск по «Моим местам»

  • Окрестности: поиск объектов, расположенных в окрестностях текущего местоположения или пункта назначения.

    Поиск в окрестностях текущего местоположения

  • Код карты: введите код карты, чтобы найти место.

    Поиск по коду карты

  • Почтовый индекс: введите почтовый индекс для поиска.

    Поиск по почтовому индексу
