Виды инструментов

Автомобиль с тремя рядами сидений

  • Ключ для колесных гаек (также служит рукояткой домкрата) (продается отдельно, хранится в сумке для инструментов)

  • Ручка домкрата (продается отдельно, помещается в сумку для инструментов)

  • Домкрат (продается отдельно)

  • Болт с ушком (ссылка на кронштейн)

Автомобиль с двумя рядами сидений

  • Ключ для колесных гаек (также служит рукояткой домкрата) (продается отдельно)

  • Ручка домкрата (продается отдельно)

  • Домкрат (продается отдельно)

  • Болт с ушком (ссылка на кронштейн)

Общее

  • Ключ для колесных гаек (также служит рукояткой домкрата) (продается отдельно)

  • Ручка домкрата (продается отдельно)

  • Домкрат (продается отдельно)

  • Болт с ушком (ссылка на кронштейн)

Инструменты можно убрать в багажное отделение.
